# Zuv for VS Code

Official Visual Studio Code support for the **[Zuv programming language](https://github.com/zuv-lang/zuv)**.

Zuv is a modern, high-performance, statically typed compiled language built on LLVM. It focuses on simple, concise syntax, memory safety, native performance, and a productive developer experience.

## Features

* Zuv `.zv` language support
* Syntax highlighting
* Language Server Protocol (LSP) integration
* Real-time diagnostics
* Code analysis
* Language-aware editor features
* Automatic communication with the Zuv Language Server
* Windows, Linux, and macOS support

## What This Extension Does

The extension connects Visual Studio Code to the **Zuv Language Server**, providing language-aware development features while you write Zuv code.

It recognizes `.zv` files and communicates with the Zuv LSP to analyze source code and provide diagnostics and other editor functionality.

The language server is maintained as part of **Zuv Developer Tools**.

## Zuv Language

Zuv is designed around the idea:

> **Write Less, Do More. Code Like You Chat.**

Key language features include:

* Parenthesis-free syntax
* Static borrow checking
* LLVM-based native code generation
* Fluent dot methods
* Native multithreading
* Async/await
* Self-hosting compiler
